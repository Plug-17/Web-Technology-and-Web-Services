
<h2> รายละเอียดโปรเจค</h2>
<p>
  โปรเจคนี้เป็นส่วนหนึ่งของวิชา Web Technology and Web Services
  รหัสวิชา 01418441 กลุ่มของพวกเราได้ทำการพัฒนาเว็บไซต์ 
 ร้านขายหุ่นโมเดลตัวการ์ตูน โดยตัวโปรเจคนี้เป็น Full Stack Application มีทั้งในส่วน Frontend และ Backend
  ทำงานร่วมกันในระบบ และมีการใช้งานฐานข้อมูลเป็น postgresql
</p>

<ul>

  <li>ระบบลงทะเบียน</li>
  <li>ค้นหาสินค้า</li>
